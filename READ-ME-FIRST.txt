PAWN TO PROFESSOR v1.9.8z — SECURE UNIT PDF GUIDES

WHAT THIS PATCH DOES
- Adds one private PDF Activity Guide slot to every Unit.
- PDFs stay in the SEPARATE Supabase Documents project.
- Main Supabase still controls login and Unit access.
- Vercel only authenticates and creates a short 5-minute signed URL.
- PDF bytes go directly from the Documents Supabase Storage project to the browser.
- This avoids using Vercel to serve the PDF file itself.

MEMBER VIEWER
- no normal Download button
- no normal Print button
- no permanent PDF URL shown
- right-click disabled in the viewer
- common Save/Print/Copy keyboard shortcuts blocked while open
- small pawntoprofessor.com watermark at bottom-right of each page
- pages render lazily as the teacher scrolls

IMPORTANT LIMITATION
A visible browser document can never be made impossible to copy. Screenshots, developer tools, and system-level capture remain possible. This patch is access control + ordinary-user deterrence, not DRM.

REQUIRED VERCEL VARIABLES
DOCS_SUPABASE_URL
DOCS_SUPABASE_SERVICE_ROLE_KEY

Your existing main variables are also used:
SUPABASE_URL
SUPABASE_SERVICE_ROLE_KEY

SEPARATE DOCS PROJECT
Private Storage bucket name must be:
unit-guides

Example file path:
grade6/unit4-activity-guide.pdf

INSTALL
1. MAIN Supabase → SQL Editor → run sql/UNIT_PDF_GUIDES_v1.9.8z.sql
2. Upload unit-pdf-guides-v1.9.8z.js and unit-pdf-guides-v1.9.8z.css to website root.
3. Upload api/unit-guide.js to /api/unit-guide.js
4. Edit index.html using INDEX-CHANGES.txt
5. Commit and wait for Vercel deployment to become Ready.
6. Login Admin → Unit Guides.
7. Choose a Unit and save only the private Storage path, for example grade6/unit4-activity-guide.pdf
8. Preview as Admin.
9. Test a normal member with Unit access.
10. Test a normal member without Unit access; the server must deny the signed URL.

100-USER / VERCEL DESIGN
- Vercel sends small JSON only.
- PDF itself is not proxied through Vercel.
- Docs Supabase Storage serves the PDF.
- Signed URL expires in 300 seconds.
- PDF pages are rendered lazily.
