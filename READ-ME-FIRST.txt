Pawn to Professor v1.9.8r — Combined Homepage Analytics

THIS REPLACES v1.9.8q.

It combines BOTH things you asked for:

A) PUBLIC / NOT-SIGNED-IN VISITS
Counts visits to the public/login page even when the visitor has never registered.

Shows:
- Public visits today
- Unique browsers today
- Public visits last 7 days
- Unique browsers last 7 days
- Public visits last 30 days
- Unique browsers last 30 days

Privacy:
- No IP address is stored by this patch.
- Each browser receives a random UUID in localStorage.
- “Unique browser” is an estimate, not a guaranteed unique person.
- One person using two devices can count twice.
- Clearing browser storage can create a new browser ID.

B) LOGGED-IN MEMBER HOMEPAGE OPENS
Uses your EXISTING analytics event:
  portal_home_view

Shows:
- Member Home opens today / 7 days / 30 days
- Unique members today / 7 days / 30 days
- Newest 50 member Home-open records with member + date/time

FILES
1. homepage-activity-v1.9.8r.js
2. SUPABASE-SQL-v1.9.8r.sql
3. INDEX-SNIPPET.txt

INSTALL — STEP BY STEP

STEP 1 — SUPABASE
Open Supabase -> SQL Editor.
Copy ALL of SUPABASE-SQL-v1.9.8r.sql.
Run it once.

This creates:
  public_home_visits
  log_public_home_visit(...)

It explicitly grants only the permissions required and uses RLS for Admin/Owner reading.

STEP 2 — GITHUB
Upload homepage-activity-v1.9.8r.js to the ROOT of the website repository.

STEP 3 — INDEX.HTML
Near the bottom of index.html you already have:
  <script src="./analytics.js" defer></script>

Immediately AFTER it add:
  <script src="./homepage-activity-v1.9.8r.js" defer></script>

IMPORTANT:
If you already installed:
  homepage-activity-v1.9.8q.js
REMOVE that old script line.
Use only v1.9.8r.

STEP 4 — COMMIT
Commit the files.

STEP 5 — VERCEL
Wait until the new Vercel deployment says Ready.

STEP 6 — HARD REFRESH
Open the website and hard refresh.

STEP 7 — TEST PUBLIC VISIT
Open a private/incognito browser window.
Do NOT log in.
Open the website login page.
Close/reopen or refresh once if you want a second page-open test.

STEP 8 — CHECK ADMIN
Log in as Admin/Owner.
Open:
  Admin -> Usage Analytics

At the top you will see:
  Homepage Activity

with TWO separate groups:
  Public visitors — not signed in
  Logged-in member Home opens

IMPORTANT MEANING
“Public visitor” means the page was opened while no account was signed in.
The system cannot know whether that anonymous person has registered before.
It deliberately does not identify them personally.

VERCEL
No new Vercel Serverless Function is added.
Anonymous logging goes directly through a tightly-scoped Supabase RPC.

DATABASE LOAD
One tiny database insert per public/login-page open.
This is lightweight for your 100-user target.
