Pawn to Professor v1.9.8p — Recipients + Unit Phonics

This patch does exactly two things:

1. Admin Messages recipient fix
- Admin -> Messages -> New Message now loads active members first if needed.
- Fixes blank recipient/member dropdown when Messages is opened directly from the Home tile.
- Active Teacher/Learner members appear in:
  One member
  Several selected members
  All Teachers
  All Learners
  All Members

2. Unit Phonics setup
- Admin -> Content Structure gets one button:
  Create Unit Phonics in Grade 1 + Grade 2
- Choose the correct school year first.
- It creates only:
  Grade 1 -> Unit Phonics
  Grade 2 -> Unit Phonics
- It does NOT create an activity.
- It does NOT add a URL.
- It does NOT merge Grade 1 and Grade 2.
- Existing Unit Phonics entries are not duplicated.

Install:
1. Replace root app.js
2. Commit
3. Wait for Vercel Ready
4. Hard refresh

No SQL.
No new /api file.
No new Vercel Serverless Function.
