Pawn to Professor v1.9.8m
Mailbox 100-message limit + Member Self-Delete + Activity Delete

WHAT THIS PATCH DOES

1) MEMBER MAILBOX
- Teacher/Learner accounts may store/send up to 100 of THEIR OWN messages to Admin.
- Admin/System messages do NOT count toward the 100.
- A visible counter shows: 42 / 100 messages used.
- At 100/100, New Message / Send / Reply are disabled.
- Members can delete ONLY messages that they personally sent.
- Delete uses: "Delete this message?" -> Cancel / Delete.
- Deleting a member message immediately frees one message slot.
- Admin/Owner remains unlimited.
- Server enforces the 100-message limit, so it cannot be bypassed by the browser.

2) ADMIN ACTIVITIES
- Adds a red Delete button to each existing Activity.
- Confirmation is required.
- Deletes the protected activity_targets row first.
- Then deletes the Activity.
- Writes an audit-log entry.
- Resources are unchanged because Resources already have a working Delete button.
