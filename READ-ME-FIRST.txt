PAWN TO PROFESSOR — GENERIC FLASHCARD STORAGE v1

WHAT THIS BUILDS
One generic saved-flashcard system for all grades, Units, lessons, teachers and learners.

LIMIT
20 saved sets per USER per LESSON.

WHY THIS ARCHITECTURE
Your interactive lessons may be hosted on another domain. Supabase login sessions do not automatically transfer between domains.

So we use:

Interactive lesson
  ptp-flashcard-storage.js
        ↓ postMessage
Learning Hub play.html
  ptp-flashcard-bridge.js
        ↓ authenticated Supabase session
MAIN Supabase
  user_flashcard_sets

ZERO new Vercel Functions.

SETUP

STEP 1 — SUPABASE
Run:
  01-GENERIC-FLASHCARD-STORAGE.sql

in:
  MAIN Supabase → SQL Editor → New Query → Run

Expected:
  Success. No rows returned.

STEP 2 — LEARNING HUB
Upload to the Learning Hub website root:
  ptp-flashcard-bridge.js

In play.html, AFTER play.js, add:
  <script src="./ptp-flashcard-bridge.js" defer></script>

STEP 3 — EACH INTERACTIVE LESSON
Put inside that lesson folder:
  ptp-flashcard-storage.js

Then add to that lesson index.html:

  <script>
  window.PTP_FLASHCARD_CONFIG = {
    unitKey: 'grade3_unit3_family_pets',
    lessonKey: 'week6_family_pets'
  };
  </script>

  <script src="./ptp-flashcard-storage.js" defer></script>

Every lesson must have its own stable unitKey + lessonKey.

STEP 4 — CONNECT THE LESSON BUTTONS
Use:
  PTPFlashcardStorage.listSets()
  PTPFlashcardStorage.saveSet(...)
  PTPFlashcardStorage.deleteSet(id)

See:
  EXAMPLE-LESSON-INTEGRATION.html

STEP 5 — TEST
1. Login as normal teacher or learner.
2. Open the lesson THROUGH the Learning Hub.
3. Save a set.
4. Refresh.
5. Load the saved sets.
6. Login as another user and confirm they cannot see the first user's sets.
7. Create 20 sets in one lesson; the 21st must be refused.

NOTES
- Teachers and learners see only their own sets.
- Admin/Owner can access all sets.
- The 20-set limit is enforced in Supabase.
- No API route is added.
- No new Vercel Function is added.
