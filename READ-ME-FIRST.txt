Pawn to Professor v1.9.8n — Conservative Performance Patch

PURPOSE
Reduce background traffic and duplicate mailbox work without changing
payments, permissions, paid Unit release, mailbox limits, or Vercel functions.

CHANGES

1. Device security check
   Before: every 30 seconds
   Now:    every 60 seconds

   Example with 30 simultaneous members:
   Before: about 60 session-status requests/minute
   Now:    about 30 session-status requests/minute

   The one-device security rule remains active.

2. Mailbox quota counter
   The 100-message count is cached for 5 seconds so DOM redraws do not
   repeatedly query Supabase.

3. Mailbox delete controls
   If delete buttons are already installed, the browser does not re-query
   the same conversation just because the DOM changed.

4. Mailbox observer
   It now ignores page mutations unless the user is actually inside
   My Messages, and uses a slightly longer debounce.

WHAT IS NOT CHANGED
- 100-message limit
- Member self-delete rules
- Admin/Owner mailbox behavior
- Payments
- Annual access
- Paid Unit Release
- Activity Delete
- Resources
- Device single-login rule
- Vercel API/function count

INSTALL
Replace ONLY the repository-root file:
  app.js

Then:
1. Commit
2. Wait for Vercel -> Ready
3. Hard refresh
4. Test login, My Messages, Delete Message, and Activities

NO SQL.
NO NEW /api FILE.
NO NEW VERCEL SERVERLESS FUNCTION.
