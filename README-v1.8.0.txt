Pawn to Professor Learning Hub v1.8.0
Teacher / Learner registration + 7-day Unit 1 trial

Main rules:
- Public registration: Teacher or Learner.
- Teacher: must confirm 18+.
- Learner under 18: guardian details + permission required.
- Admin approval starts one 7-day trial automatically.
- Trial unlocks every published Unit 1.
- Trial expiry removes only trial access; account stays active.
- Paid/direct/group access continues after trial expiry.
- Ordinary Teacher and Learner accounts do NOT see Teacher Tools.
- Admin/Owner retain Teacher Tools.

Install SQL first, then deploy the new/updated files.
Read SETUP-v1.8.0.md before installing.
